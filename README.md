# ♟️ Lichess AI Companion Plugin (Uranus iMessage 扩展模块)

面向 AI 情感陪伴场景开发的 **Lichess 实时国际象棋对弈与互动插件**。  
打破传统大模型“纯文字一问一答”的单一交互模式，让 AI 角色能够接入真实在线对弈平台，实现**“共享娱乐场景下的沉浸式陪伴”**。

### ✨ 核心设计亮点
* **双向主动对弈机制**：支持 AI 角色根据当前对话情绪主动向用户发起棋局邀约，或实时响应用户的对局挑战。
* **棋局状态与行为感知**：实时监听 Lichess 棋局走法与对局状态变化，支持超时管理与长考触发机制（在用户思考过久时主动发送符合人设的催促或关怀消息）。
* **中盘情感互动节流 (`maxMidGameTalks`)**：内置中盘对话频率控制参数，避免 AI 在对弈过程中刷屏打扰思考，在关键落子节点结合角色人设自然吐槽、鼓励或互动。
